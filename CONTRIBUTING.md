# Contributing

Thanks for helping improve Tianji Decision Council.

## Principles
- Add analytical value, not celebrity name-dropping.
- Cite reliable primary or authoritative sources for factual claims.
- Clearly distinguish a thinker's documented ideas from later interpretations.
- Include limitations, counterarguments, and contexts where the model should not be used.
- Do not add copyrighted book chapters, paywalled content, or large verbatim excerpts.
- Keep Chinese and English terminology aligned where practical.

## Proposing a new thinker
Submit:
1. name and historical context;
2. primary works / reliable references;
3. distinctive decision lens;
4. 3–7 operational questions or tools;
5. limitations and common misreadings;
6. one test scenario showing when this lens adds value.

## Testing changes
Run the scenarios in `tests/`. A change should improve factual discipline, reasoning quality, disagreement quality, or actionability without adding false certainty.
